Short description

iriz is a local-first contextual memory for macOS that turns meaningful commitments and unfinished work into clear Actions.

Boilerplate

iriz is a native macOS contextual memory designed to preserve the useful moments that disappear between apps, tabs, and conversations. It detects meaningful changes, filters routine activity, and keeps useful evidence in encrypted local memory. Actions turn meaningful commitments and unfinished work into manageable next steps. Ask iriz searches locally first and answers from a bounded set of relevant sources. iriz never captures keystrokes, clipboard contents, or camera video. Raw media is encrypted locally and expires after 24 hours.

Core messages

What makes iriz different.

01

Context becomes Action.

iriz turns meaningful commitments and unfinished work into understandable next steps instead of a noisy activity log.

02

Answers stay sourced.

Ask iriz searches locally first and uses only bounded relevant memory and limited thread context for each answer.

03

Privacy is architectural.

Memory is encrypted locally, raw evidence expires, private sources stay unnamed, and observation can be paused instantly.

Asset guidance

Keep it recognizably iriz.

  • Always write the product name as iriz, including at the beginning of a sentence or title.
  • Use the supplied icon without cropping, rotation, recoloring, or added effects.
  • Use Actions for the context-aware next steps iriz creates from meaningful commitments and unfinished work.
  • Describe the product as local-first, not fully offline: enabled AI features send selected requests directly to OpenAI.
  • Do not claim App Store, Setapp, or direct-download availability until the relevant release is live.
